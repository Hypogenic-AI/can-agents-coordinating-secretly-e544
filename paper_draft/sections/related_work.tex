\section{Related Work}
\label{sec:related}

\para{Provably secure and keyless steganography.}
The prisoners' problem asks how two parties can communicate under a warden's eye. \citet{cachin1998information} gave an information-theoretic definition, and \citet{hopper2002provably} gave a complexity-theoretic one with a rejection-sampling construction. Both assume a shared key. LM-based schemes extend keyed steganography to model outputs, using pseudorandom functions~\citep{christ2023undetectable,zamir2024excuse}, minimum-entropy coupling~\citep{dewitt2022perfectly}, and pseudorandom codes~\citep{christ2024pseudorandom}. Removing the key requires interaction. \citet{vonahn2004public} introduced public-key steganography and steganographic key exchange, which need high min-entropy per message, and \citet{horel2019subvert} gave related keyless constructions. \citet{vaikuntanathan2026undetectable} showed that two LLM agents with no shared secret can run an undetectable key exchange, needing only constant min-entropy per message and public randomness. \citet{pang2026codetta} implemented a lattice-based version (Codetta) that sets up a 128-bit key in about 80k tokens. \citet{zhang2025public} built public-key steganography from admissible encodings. All of these works state that the parties ``have agreed on the covert protocol.'' Building on them, we ask what this protocol agreement costs and what it implies for a monitor that knows the protocol too. We reuse their construction in a small, open form to measure costs and fragility.

\para{Steganographic collusion between LLM agents.}
\citet{motwani2024secret} formalized secret collusion among generative agents, including common knowledge, Schelling points, and grounding, and found that steganographic capability grows with scale. \citet{mathew2024hidden} showed that steganographic collusion emerges under misspecified rewards and that paraphrasing does not fully stop it. \citet{zolkowski2025early} found that frontier models rarely pass a hidden message past a monitor without a pre-agreed scheme, but can with one. \citet{rippin2026tool} showed that agents with code tools can build provably secure stegosystems themselves. Unlike these empirical studies, we compare the partner to an auditor that runs the \emph{same} model, which isolates the colluders' advantage from the monitor's capability.

\para{Tacit coordination and shared weights.}
Schelling's focal points~\citep{schelling1960strategy} and cheap-talk theory~\citep{crawford1990focal} explain how agents can coordinate without talking. \citet{jarviniemi2025subversion} measured LLM focal-point collusion directly: two Claude instances succeeded in 3.4\% of attempts. \citet{aharon2026tacit} found that LLMs match humans on many focal-point games. \citet{cloud2025subliminal} showed that traits pass through unrelated data only when teacher and student share a base model, so shared weights can act as a correlated secret. Self-recognition, which might otherwise serve for authentication, is weak in current models~\citep{davidson2024self}. Our Kerckhoffs--Schelling corollary gives the monitor-side view of these results: focal points and weight idiosyncrasies are secret only from monitors that lack the knowledge or weights.

\para{Active defenses.}
Paraphrasing limits how much information encoded reasoning can carry~\citep{roger2023preventing}, and re-randomization attacks destroy many LM stegosystems~\citep{perry2025robust}. \citet{tailor2025audit} analyzed the capacity left after paraphrasing and rate limits. Meaning-level channels can survive paraphrase~\citep{zhou2026conceptual}. \citet{vaikuntanathan2026undetectable} and \citet{pang2026codetta} suggest active probing and verifiable sampling as the main defenses. We add a precise impossibility for impersonating wardens and an empirical mechanism, desynchronization, that makes entropy-gated channels much more fragile than the usual binary-symmetric-channel model predicts.

\para{Emergent communication.}
Agents trained jointly develop arbitrary codes~\citep{foerster2016learning,kottur2017natural,lazaridou2020emergent}, and neural agents can learn to hide messages from an eavesdropper given a shared key~\citep{abadi2016learning}. In our terms, joint training supplies the protocol $P$ (and possibly correlated randomness). We do not train agents. We focus on agents that never interacted before.
